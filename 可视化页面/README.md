# 研究可视化档案

双击本文件夹中的 **启动可视化.cmd**，将自动启动本地服务并打开档案首页：

http://127.0.0.1:8870/

关闭浏览器不会停止后台服务。再次双击启动文件会复用已有服务，不需要启动旧的8000或8765服务。仅监听本机127.0.0.1；未设置开机自启。

## 页面目录

| 文件夹 | 内容与边界 |
|---|---|
| 课题故事与期刊调研_20261117 | 通俗故事、实测证据、期刊范围、三分钟讲稿；单文件离线页面，可直接双击HTML。 |
| giant_constellation | 你要找的巨型星座总览：Starlink、OneWeb、GSO卫星及网关/GSO参考接收点。全部既有目录卫星、243条站点记录；三维地球、系统开关、网关查询与轨道回放。 |
| v1_1 | 61帧几何与活动馈电关联；没有干扰和LF计算。 |
| v1_2 | 首快照物理干扰；保留原始半宽1°基准，不替换为后续参数。 |
| v1_3 | 61帧LF、固定发射方向图与频率缩放补充对照；提供敏感性原始结果。 |
| v1_4 | NGSO LF、GSO原3.5m频道功率诊断及筛选原型结果；不是EPFD保护计算。 |
| v1_4_1 | 独立1/2/5m、40kHz/1MHz参考窗口EPFD，两种历史频点诊断安排。 |
| v1_5 | 扩展集合、站内无重频随机分配，两小时720帧开环干扰计算，含LF、EPFD和耗时。 |

各版本有独立HTML和数据副本，不通过共享的场景API切换场景。V1.2–V1.4.1的新展示页读取旧计算结果生成，没有重新运行或修改旧物理实验。V1.1–V1.4.1使用原6+6个NGSO网关输入，不能与V1.5扩展集合直接作性能归因比较。

巨型星座总览使用2026-11-13T12:00:00Z起两小时、60秒间隔的121个轨道展示快照（包含终点）。这是为独立回顾生成的轨道缓存，不是V1.5的720帧干扰结果。显示全部候选目录记录，不按活动链路筛选；位置为用于展示而四舍五入到1m的ECEF坐标。站点和轨道文件来源哈希保留在该页config.json中。

三维页面的Cesium库和OpenStreetMap底图需要网络。浏览器需支持DecompressionStream；推荐当前Chromium浏览器。不能直接双击HTML以file协议读取数据，应使用启动文件。

## 维护

- 原项目、历史结果和V1.4.1冻结快照保持不变。
- manifest.json记录档案文件SHA256；service.log属于运行日志，不纳入静态文件审计。
- 页面属于历史回顾，不把采样EPFD解释为完整法规合规，也不把社区近似站址或仿真点解释为真实运营站。
- Python环境仍使用项目根目录下的.venv-ems，单独移动整个文件夹时需调整启动脚本中的Python路径。
