# 八站细化复核方法

固定原八站，脚本 `scripts/refine_gateways.py` 使用原72小时、25°、60秒扫描，找出任一站可见星数≤2的采样点，在其前后扩展窗口内进行5秒复核。保留原始全部60秒时间点。非均匀样本不能直接平均用于全时段覆盖率；全时段比例只使用均匀60秒子集。

`low_intervals.csv` 记录相邻低候选粗采样点的连续段，不声称是精确过境起止时刻。细化不能发现远离所选窗口的所有短缺口。

候选链路输出为gzip CSV：时间、站点、NORAD编号、仰角、斜距、三个假设损耗下的容量。输入和时间尺度沿用主扫描。

探索性预算使用48 GHz、250 MHz、GS EIRP=65 dBW、星上G/T=5 dB/K、实现间隙3 dB、频谱效率上限6 bit/s/Hz，额外损耗为3/10/20 dB。公式：

- FSPL[dB] = 92.45 + 20log10(d[km]) + 20log10(f[GHz])。
- C/N[dB] = EIRP + G/T − FSPL − L + 228.6 − 10log10(B[Hz])。
- C = B min(6, log2(1 + 10^((C/N − gap)/10)))。

这些数值只是显式可审查的敏感性假设，不是公开Starlink设备参数，不构成所选频率获得授权或符合EESS保护的证据；额外损耗不是ITU降雨模型，也不是干扰模型。

接入限制阶段：假设每站需要一个卫星连接，每颗星最多连接K=1/2/4个GS，通过广义Hall条件枚举全部255个非空GS子集，精确判断每个粗时刻能否同时分配8站。该判定不包含容量、切换、天线转向和频谱冲突。

容量阶段的当前输出仅是逐站全部候选链路容量之和这一乐观上界：上界仍不足说明必然不足，上界充足不说明可分配。配置中的卫星总容量1/2/4 Gbps预留为后续联合流量分配实验，当前尚未施加。不能把该输出当成QoS调度结果。

后续需要先审查上述参数，再增加卫星共享容量、GS天线数、业务类别、功率/带宽共享、干扰与保护门限，执行可行流分配与基线对比。无用户路径模型时只能评价GS侧负载满足，不能称为用户端到端QoS。
