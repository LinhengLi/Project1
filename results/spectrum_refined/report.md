# 50 GHz 馈电上行发射限值配对实验

两个冻结窗口均为 120 秒。保护开／关都使用 50.0 GHz、250 MHz 和同一几何。
抑制度是天线端口带内总功率与 50.2–50.4 GHz 积分泄漏功率之差。
按 Resolution 750 所选情形，打开保护时施加 −42 dBW / 200 MHz 端口限值。
采用固定谱形与固定发射功率设定。前瞻调度读取已保存的未来状态。
本轮词典序目标锁定容差为 0.0001 Gbit。

## 模型输入

按 P.676-13 附录 1 和 P.835-7 参考大气计算，逐边气体衰减为 1.548–3.651 dB。
另外设置 0 dB 余量。沿用冻结几何的站高，以几何仰角近似地面视仰角。
保留旧抑制度扫描作受控比较。另将 SM.1541 通用 FSS 掩模积分为独立包络情景，以平坦带内谱和单信道指配为假设。
通用掩模包络的积分抑制度为 14.4850 dB。它用于检查包络情景的边界，设备实际泄漏需要独立数据。

本实验只评估单发射端口限值情景。抑制度与天线增益需用设备资料校准，传感器接收端的聚合干扰、真实授权和端到端网络性能属于另外的测量问题。
