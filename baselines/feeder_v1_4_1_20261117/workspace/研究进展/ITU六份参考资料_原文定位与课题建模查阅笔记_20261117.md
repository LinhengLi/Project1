# ITU六份资料查阅笔记：原文定位、摘录与建模用途

整理日期：2026-11-17。对应研究：NGSO–NGSO–GSO异构共存下动态快速干扰计算。

**阅读说明**：本笔记覆盖本课题当前已识别的相关内容，不是六份文件的全文翻译或逐页审定版。受原文转载限制，每份资料仅保留短原文摘录；长段落通过官方全文和章节号查阅。下述“要点”均为中文概述，“本项目使用建议”为研究判断，不能当作ITU原文。公式详录与条款表格通过末尾项目文档链接交叉引用。

## 1. ITU-R S.1503-4（09/2023）

### 官方原文

[英文PDF](https://www.itu.int/dms_pubrec/itu-r/rec/s/R-REC-S.1503-4-202309-I!!PDF-E.pdf) · [官方版本目录](https://www.itu.int/rec/R-REC-S.1503/en)

中文主题：用于开发软件、检验非GSO FSS系统是否符合《无线电规则》Article22限值的功能描述。PDF本轮直接请求曾超时，随后通过已索引的官方同一文件读取成功；不是使用其他版本代替。

### 短原文摘录

> The reference bandwidth of the mask is required

位置：§C4.1，印刷页37。译意：需要明确掩模的参考带宽。

### 相关原文导航

| 原文章节 | 查阅重点 |
|---|---|
| Part B；§B3.3、§B5.3 | 运行参数及校验 |
| Part C，尤其§C4.1 | 掩模、频率范围、参考带宽与带宽换算 |
| §D3、§D3.1 | 最坏几何、地球站与GSO指向 |
| §D4、§D4.5、§D4.7 | 步长、时长、细/粗采样 |
| §D5.1.1–D5.1.3 | GSO、非GSO及运行输入 |
| §D5.1.4、§D5.1.5 | 下行逐时刻流程与pfd掩模计算 |
| §D6.5 | GSO参考方向图 |
| §D7.1、§D7.3 | 统计判定与结果输出 |

### 方法要点概述

正式验证包含运行配置、最坏几何与统计检查。下行流程使用pfd掩模，并结合接收天线离轴增益。§C4.1的恒定谱密度带宽修正为：

`level_calc = level_mask + 10*log10(B_threshold/B_mask)`。

两种带宽必须同单位。D4的采样设计不是任意固定10秒；D5.1还区分跟踪持续时间等运行策略。固定位置的研究运行与全系统验证不能混称。

### 本项目使用建议

先实现参考窗口与逐源贡献接口，再做采样收敛。当前活动波束逐对计算可以作为研究参考内核，但不冒充完整掩模申报软件。该资料提供既有方法基准，不能把其流程本身写成我们的创新。后续快速计算须与同一输入、同一采样口径的参考结果比较。

## 2. ITU-R S.1428-1（2001）

### 官方原文

[英文PDF，第2–3页为公式](https://www.itu.int/dms_pubrec/itu-r/rec/s/R-REC-S.1428-1-200102-I!!PDF-E.pdf#page=2)

中文主题：10.7–30GHz频段内，涉及非GSO卫星干扰评估的FSS地球站参考方向图。

### 短原文摘录

> This Recommendation is based on studies of a range of paraboloid antennas.

位置：第3页Note2。译意：该建议书依据多种抛物面天线的研究。

### 原文导航及要点

| 位置 | 内容 |
|---|---|
| 第1页considering c)–g) | 动态干扰需要覆盖不同离轴角和电尺寸 |
| 第2页recommends1 | q=D/lambda的20至25、25至100两档 |
| 第3页公式 | q>100一档 |
| 第3页Notes1–4 | 极化简化、天线类型及术语适用性 |

公式输出dBi，角度用度；q<=100和q>100的峰值分别含7.7与8.4常数，不能混用。0度在代码取主瓣极限；q<20不外推。Note1中的交叉极化处理有特定情境，不是所有极化条件都相同。平面阵列适用性仍需研究。

### 本项目使用建议

继续作为GSO参考接收方向图。明确口径和频率，不再额外独立指定不一致的固定峰值；保留0度及分段边界测试。冻结3.5m假设设备与1m/2m/5m参考配置分别管理。完整分段公式已在[方向图核查报告](ITU_S1528-0_S1428-1_天线方向图核查报告.md)第三节记录，不在此重复转录。

## 3. ITU-R S.1323-2（2002）

### 官方原文

[英文PDF](https://www.itu.int/dms_pubrec/itu-r/rec/s/R-REC-S.1323-2-200209-I!!PDF-E.pdf)

中文主题：30GHz以下同向FSS网络间允许干扰水平及其性能评价方法。

### 短原文摘录

> for non-GSO to GSO interference

位置：第4页recommends11。译意：对于非GSO对GSO的干扰；该处接续指定使用S.1428方向图。

### 原文导航及要点

| 位置 | 内容 |
|---|---|
| 第2页recommends1、2 | GSO间的聚合及单入口预算 |
| 第3页recommends3 | 时变干扰和短期性能/自适应编码 |
| 第4页recommends7–10 | 不同方法、长期补充与干扰掩模 |
| 第4页recommends11 | 接收天线模型 |
| 第4–5页Notes1–6 | 适用关系、热噪声等效、衰落、非均匀频谱 |
| Annexes1、2 | 性能退化和统计方法的进一步推导 |

单个其他GSO网络的6%噪声预算与NGSO时变干扰不能混为一条规则。recommends9的6%/10%时间关系有方法适用条件，不能删掉时间维度。时变干扰可能包含恒定分量；部分方法适用性仍有保留说明。

### 本项目使用建议

当前−12.2dB继续只作论文对齐NGSO研究判据，不能据此宣称GSO法规合规。以后若评估业务损失，需要额外明确BER/CN、衰落及编码模型；现阶段只做功率和EPFD参考计算，不扩张为业务级可靠性结论。

## 4. ITU-R S.1432-1（2006）

### 官方原文

[英文PDF](https://www.itu.int/dms_pubrec/itu-r/rec/s/R-REC-S.1432-1-200604-I!!PDF-E.pdf)

中文主题：30GHz以下FSS参考数字链路在时间不变干扰下的误码性能退化预算分配。

### 短原文摘录

> 6% for other systems having co-primary status

位置：第2页recommends4。译意：给其他具有共同主要业务地位的系统分配6%。注意它在此处的对象和语境。

### 原文导航及要点

| 位置 | 内容 |
|---|---|
| 第1页Scope | 参考数字链路及性能目标背景 |
| 第2页recommends3 | 总干扰预算 |
| 第2页recommends4 | 来源分类预算 |
| 第2页Notes1、2 | 与其他建议书的关系 |
| Annex1，§3、§5 | 百分比与性能、总结 |

不复用/复用频率时，总预算分别为晴空系统噪声的32%/27%；其他FSS分配25%/20%，其他共同主要业务6%，其他来源1%。该文不替代S.1323等文件。不同文件中出现相同百分比不意味着适用对象相同。

### 本项目使用建议

不能只因10log10(0.06)约为−12.22dB，就推出所有NGSO对GSO必须逐时隙采用此门限。当前门限的直接来源仍按精读论文记录。需要接收机I/N时，噪声参数、带宽及干扰来源分类显式配置；不得把预算比例当成发射功率上限。

## 5. ITU-R S.1589-0（2002）

### 官方原文

[英文PDF，Annex2从第11页开始](https://www.itu.int/dms_pubrec/itu-r/rec/s/R-REC-S.1589-0-200209-I!!PDF-E.pdf#page=11)

中文主题：对Article22未直接列出口径或波束宽度，近似估计其保护水平的连续曲线。

### 短原文摘录

> only intended as best approximations

位置：Annex2 §1，第11页。译意：仅旨在提供尽可能好的近似。

### 原文导航及要点

| 位置 | 内容 |
|---|---|
| 第2页recommends及Notes1、2 | 设计指导属性与带宽换算 |
| Annex1 | 10.7–12.75GHz，不能误用于本项目 |
| Annex2 §1 | 本频段拟合的条件 |
| Annex2 §2、Table3 | 本频段历史表列点，注意时间百分比方向 |
| Annex2 §3，式19–23 | 17.8–18.6GHz连续口径拟合 |
| Annex3 | 上行参考空间站波束，不是当前地球站下行模型 |

Annex2本频段口径范围1–5m、参考带宽40kHz，适用条件包括GSO倾角小于2.5°和纬度低于60°。拟合有约1dB误差，5m可达3dB。文中p为可超过的时间百分比，不是RR表中的不得超过比例。

### 本项目使用建议

3.5m可在条件核对后独立研究近似曲线，但首版保护参考优先采用表列1m/2m/5m。不要将拟合曲线包装成3.5m的精确法规限值，也不要未经核查扩展至第76号决议聚合表。若实现式19–23，必须同时保存p的定义、单位、适用范围和拟合误差说明。

## 6. ITU EPFD Support Q&A

### 官方原文

[Questions & Answers](https://www.itu.int/epfdsupport/questions/)

网页无稳定页码，以下按问题主题及浏览器查找词定位；页面不同段落更新程度可能不同。

### 短原文摘录

> EPFD limits in article 22 are applied to a non-GSO system

位置：问题查找词“single non-GSO satellite”。译意：Article22的EPFD限值作用于一套非GSO系统。

### 问题导航及要点

| 浏览器查找词 | 用途 |
|---|---|
| Equivalent Power Flux Density as opposed | 为什么需要接收方向性加权 |
| single non-GSO satellite | 单系统与单颗卫星的区别 |
| Why do I need EPFD examination software | 运动、多源与统计计算 |
| frequency bands not subject | 没有EPFD表列限值时的协调问题 |
| What are pfd/eirp masks | 发射包络与输入掩模 |
| different pfd | 不同轨道、掩模及运行参数 |
| EPFD Validation Software | 工具背景，版本信息需另核查 |

EPFD是指定参考带宽内、多方向辐射经接收天线方向性加权后的等效通量。掩模用于表征系统辐射包络，并非选取某次有利配置。页面存在仍称S.1503只有旧版或软件基于第2版的段落，同时也有引用第4版的更新内容，不能用旧段落认定最新标准或软件实施状态。

### 本项目使用建议

用于概念解释和进一步文献导航，不代替RR限值、正式建议书和工具版本说明。候选目录不等于同时发射集合；一个系统内的多波束和多星贡献需要一致聚合。多系统聚合仍另查第76号决议及其适用计算方法。
