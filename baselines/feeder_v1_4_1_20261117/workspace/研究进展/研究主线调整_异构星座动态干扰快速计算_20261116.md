# 研究主线调整：异构星座动态干扰快速计算

日期：2026-11-16。性质：用户确认的研究定位与后续规划，不是已完成的创新成果或实验结论。

## 核心定位

研究重点为NGSO–NGSO–GSO异构共存场景下的动态快速干扰计算算法。联合选星、频率分配、功率控制或最大馈电容量优化，不作为当前主要创新点，而作为快速干扰计算算法成功后的具体应用展示和验证任务。

核心问题：卫星运动、活动关联和频率配置变化时，如何减少重复计算，快速更新链路间与聚合干扰，并控制误差，尤其避免漏判有害干扰。

GSO角色保持为固定受保护接收关联；固定关联不意味着干扰角度或接收干扰固定。NGSO卫星是移动干扰源，需动态计算其对GSO受保护地球站的干扰。NGSO的I/N与LF指标、GSO保护/EPFD指标必须区分，不将单时刻筛查等同于法规合规结论。

工作题目暂定：面向NGSO–NGSO–GSO异构共存的动态干扰快速计算方法。AI是否写入最终题目，取决于实际方法与实验，不提前锁定。

参考计算是在既定物理模型与参数假设下的逐对计算基准，不是实际无线环境的绝对真值。记录初建时尚未完成GSO受保护矩阵和EPFD；截至2026-11-17，V1.4/V1.4.1已完成指定场景的GSO参考矩阵与EPFD窗口计算，非AI有界筛选原型尚未取得加速，GG/CTS仍未实现。

## 候选算法方向

1. 少算干扰对：利用几何、方向增益与干扰上界筛选贡献小的干扰对。需要约束被省略项的累计功率，不能只逐项设小阈值而忽略大量弱干扰叠加。
2. 复用跨时刻结果：利用轨道和关联的连续性进行增量更新。换星、换频、方向图分段切换等可能要求重算，不能无条件复用。
3. 控制近似风险：研究误差估计、保守上下界，以及对接近保护门限或误差过大链路的逐对计算回退机制。
4. 学习辅助：AI可用于候选筛选、变化预测或误差预测，但应先测量瓶颈、建立非AI方法，再判断必要性。AI不是预设必须采用的技术。

以上为待研究和文献核查的候选方向，不宣称已证明新颖性或已取得加速效果。最终创新应由具体结构、方法、误差/可靠性机制与实验支持。

## 评价体系

- 计算效率：端到端耗时、加速比、预处理/筛选/更新/回退开销，以及随活动链路、候选规模和GSO保护接收点数变化的扩展性。
- 数值准确性：单对和聚合干扰功率误差、I/N误差，以及单独定义的GSO保护指标误差；明确线性与dB统计口径及零功率处理。
- 判定可靠性：门限附近的误差、有害干扰漏判率与误报率；漏判应作为重点。
- 下游影响：快速计算接入频率分配或联合优化后，决策质量损失、约束违反情况和整个求解过程的加速，而非只报告预测模型推理时间。

比较必须使用相同输入与物理假设；需要区分模型误差、近似计算误差及下游优化误差。当前13项测试通过是已有具体检查的结果，不构成全面物理正确性或设备真实性证明。

## V1.4推进顺序调整

1. 补齐NGSO活动发射源对GSO固定保护接收关联的逐对参考计算；明确发射指向、接收离轴、频率/参考带宽、接收天线及数据来源，不提前执行未核实EPFD法规限值。
2. 以现有61帧为初始验证输入，测量几何、方向图、逐对功率及聚合等环节耗时，明确参考计算瓶颈。
3. 设计第一版非AI快速计算方法，并与逐对基准比较速度、误差和保护判定可靠性。
4. 结果成立后再研究学习辅助及更大规模；选择GG/CTS或联合优化作为下游应用验证。

不必先完成整套联合优化或先复现全部GG/CTS，也不急于扩展2小时可视化。现有冻结版本保持不变，新增工作创建派生版本。
