# 参数整理核对与后续实现约定

核对日期：2026-11-15。用户随后授权更新，两份参数文档已按本核对结果修订；冻结feeder_v1仍不改写。物理方向图、干扰、图算法及EPFD尚未接入，几何关联按派生实验单独实现。

## 可以采用的内容

已对照 arXiv:2505.12429v1 HTML 的系统模型、Table I及VI-A：论文采用12dBW、卫星峰值35dB、网关峰值45.76dB、398K、20GHz、500MHz、40°；每条链路占一个子信道，网关轮流按最大仰角选星。用户材料将这些与本课题18.2GHz/800MHz扩展分开，是正确的。

数值独立复核：12dBW=15.8489319246W=42dBm，峰值EIRP=47dBW；398K下100MHz噪声为-122.6003364525dBW（-92.6003364525dBm），62.5MHz为-124.6415362790dBW。JSON这几项数值一致。

三组频率模式保持独立：主实验18.2GHz/800MHz；带宽控制18.2GHz/500MHz；论文物理参数控制20GHz/500MHz。后者仍使用不同的轨道/网关，不能称为论文整场景复现。固定每载波总功率会使较窄带宽下PSD增大，必须在结果解释中说明。

NGSO物理链路、两端离轴角、线性聚合、LF分母、连续关联FSR，以及单系统/跨系统干扰分类可作为后续实现依据。服务卫星要求>=40°，但计算干扰源是否可见时应使用目标接收站地平线，而非也施加40°服务仰角。

GG/CTS参数与论文VI-A一致：100次试探，CTS 2000初值/500候选/250轮/10邻居。论文同句还将100次用于Global；需明确Global实现的重复次数、排序和随机性，不可默认单次然后直接声称严格参数对齐。

## 原整理中需更新或补核的事项

1. OneWeb不是仍只有4个FCC坐标：已补Clewiston（OW-FCC-005，DOC-355200A1）和Santa Paula（OW-FCC-006，DOC-358650A1，后续授权DOC-376504A1）。因此冻结基线是6个带FCC坐标来源站；全量扩展场景为6个FCC+7个区域仿真位置。FCC记录不证明当前运营状态。原文档的“余2站需核验”是对较早状态的提醒。
2. GSO口径改变：冻结v1是3.5m/效率0.65；新材料建议EPFD参考天线1m，并列2m/5m。这是不同实验配置，不能在原v1上静默替换。以后可在v1.1中区分地面接收站的场景关联与EPFD参考天线配置，主参考1m和敏感性2m/5m明确命名；首次实现前核实方向图的D/lambda条件、峰值与曲线匹配。
3. EPFD限值数组本轮未逐行对照《无线电规则》原表。包括表号、40kHz/1MHz对应关系、百分比方向、重复百分比的分段跳变、每条参考口径及适用条件，均不能仅凭JSON视为验证通过。先作为待核对候选，正式实现用来源页码/表格逐条确认，不生成合规结论。1MHz结果不能简单复用40kHz数组。
4. “轮询最高仰角”还需锁定网关初始顺序、每轮是否轮转、卫星和网关ID平局规则。建议初版按网关ID固定顺序逐轮选星，严格同运营商、每星最多1条活动关联，保存初始顺序作敏感性对照。
5. 方向图版本已命名，但公式仍需检查自由参数：发射半功率波束宽度、旁瓣参数，接收口径/效率或D/lambda、适用分段范围。仅给峰值不足以唯一确定完整方向图；需要按历史版本逐项锁定，不能任意补数后标成论文精确复现。
6. -13dB是论文构图截断参数，在双星座及新带宽下仍要检查弱干扰累积误差；构图必须从潜在同频干扰生成，不能依赖尚未决定的颜色。单向强度保留，任一方向强则连无向边属于我们的明确实现约定。
7. CTS还要补禁忌表长度、终止与无可行邻域处理、初始解筛选准则、随机种子流；GG补度扰动方差/平局规则。已给出的四个计数不构成完整可复现算法。
8. 720个10秒区间与含初始点的721个时间快照需分开，FSR用相邻两时刻仍保留的卫星-网关关联计数；无保留关联时记NA而非任意填0。

## 研究与实施定位

采用“论文物理模型与GG/CTS方法复现 + 异构场景迁移 + 动态计算AI加速”。主评价是NGSO LF、FSR、端到端与分阶段耗时，GSO为独立保护筛查。两星座归一化RF参数作为首个可控基线，后续增加天线和功率差异，不能把归一化假设写成真实设备异构性。

继续先做：轨道清洗/统一几何 → 活动链路 → 方向图与干扰矩阵 → Random/Global/GG/CTS → TCFA → GSO保护筛查 → 瓶颈测量与AI。AI应与全量精确计算和传统增量更新比较，保留聚合物理校验。
