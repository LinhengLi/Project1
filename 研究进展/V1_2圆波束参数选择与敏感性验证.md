# V1.2 圆波束参数选择与敏感性验证

日期：2026-11-16。以用户确认有效的方向图核查报告为依据，不再获取S.1528-0原文。未扩展2小时仿真、未接入可视化、未实现图着色。

## 采用模型与研究基线

明确采用S.1528-0 recommends 1.2圆波束（z=1），a=2.58、b=6.32、alpha=1.5。模型分支是本研究选择，不宣称已核实为原论文具体分支。保留报告的分段边界与可能的跳变，不擅自平滑。

| 参数 | 选择值 | 状态 |
|---|---:|---|
| 发射峰值增益 | 35 dBi | 沿用既有论文对齐配置 |
| 参考频率 | 18.2 GHz | 冻结主频率 |
| 口径效率 | 0.6 | 新增研究假设，不是设备披露或ITU强制值 |
| 推导口径 | 0.380648 m | 由峰值、效率、频率推导 |
| 半功率半宽 | 1.499050° | 由口径近似推导 |
| 全HPBW | 2.998100° | 约3° |
| 近旁瓣等级 | −20 dB | 受允许档位约束的研究基线 |

推导采用q=sqrt(10^(Gm/10)/(eta*pi²))，D=q*c/f，半宽=sqrt(1200)/q。选定峰值、效率后不再独立随意指定口径与波束宽度。−20dB保留原诊断的中间档位，选择未以本帧LF最低为目标；−15/−25/−30dB保留为敏感性对照。效率0.6同样是可变研究假设，不代表已确认真实硬件。

旧1°半宽结果保留作为历史诊断；后续研究基线采用本文件及selected_profile.json，尚未静默改写旧single_slot_summary.json中的配置。S.1528-0 1.2模型允许峰值与宽度输入，工程耦合用于本次选参，不构成天线物理可实现性的完整证明。

## 扫描设置与结果

复用V1.1首帧66条活动链路，保持位置、功率、接收端及频点诊断安排一致，仅替换发射方向增益。半宽扫描0.5、0.75、1、1.25、1.5、1.75、2度，加选定推导半宽；旁瓣扫描−15、−20、−25、−30dB，共32组参数、64个诊断统计。通过旧矩阵乘以新旧发射增益线性比计算，几何、可见性和接收增益保持不变。

固定35dBi扫宽度意味着隐含口径效率也变化。例如0.5°对应约0.067，2°对应约1.068；因此2°仅作数学压力点，不能视为普通圆口径效率<=1的可实现设备配置。不得把整个扫描集合统称为可实现硬件设计。
