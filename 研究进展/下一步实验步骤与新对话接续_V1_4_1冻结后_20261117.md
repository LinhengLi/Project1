# 下一步实验步骤与新对话接续（V1.4.1冻结后）

日期：2026-11-17。本轮仅冻结V1.4.1、记录计划；扩展仿真与网页开发尚未开始。

## 一、研究定位

核心是NGSO–NGSO–GSO异构共存下适合干扰管理的动态快速计算算法。联合优化是应用展示，AI在瓶颈测量后决定。不做完整ITU合规工程，不以完整申报掩模、全球最坏几何或长期统计为前置条件。参考模型仅在发现错误、比较不公平或假设影响算法结论时针对性修订。

## 二、冻结基准

冻结目录：`baselines/feeder_v1_4_1_20261117`。保留相对目录结构、代码、输入、研究文档、结果、测试和环境记录，以及manifest.json。运行`scripts/freeze_feeder_v1_4_1.py`，首次创建，重复执行仅核验快照，禁止覆盖。后续修改创建派生实验，不修改原feeder_v1或本次快照。

当前已实现NGSO双端离轴角、同频聚合、I/N、LF及三类干扰；GSO独立参考窗口EPFD，分别统计Starlink、OneWeb与合计。61帧、12个NGSO网关、12条GSO保护关联。相关20项测试通过，冻结时重新运行并保存日志。

## 三、下一次实验目标与设置

建立“最大仰角选星＋随机子信道分配＋逐对完整动态计算”的两小时开环基准，输出失效、EPFD、耗时曲线与网页回放。完整候选星座用于传播/选星，只有活动馈电发射源参与干扰；实际计算规模由活动链路决定，不预先宣称必然巨大。

- 使用此前构建的扩展星座/网关集合与12条GSO固定保护关联，不另行擅自扩充数据。
- 先审查`em-situational-system-main/em-situational-system-main/data/scenarios/three_constellations.json`及轨道来源。本轮只读检查该文件共243个站点记录，应按系统、角色和来源确认采用集合，不能把243直接视为NGSO网关数。
- 10秒采样、7200秒，主统计720个起点快照：0、10、…、7190秒。7200秒终点若另算应单列。
- 起始UTC优先沿用2026-11-13T12:00:00Z；改变时记录理由、轨道epoch偏移，不静默换成当前时间。
- 选星：同运营商、网关ID升序轮询，每轮每站取一颗最大仰角未占用候选；同仰角按卫星ID；最低40°；每站最多8条、每星最多1条。
- 随机分频主方案建议站内无放回随机分配8频道、站间复用。用户尚未单独最终确认站内是否允许重频；实施前明确记录，允许重频的独立随机分配可作压力对照。随机本身是基线分配规则，准确表述为“无优化分频”。
- 建议种子20261115；按种子/帧/网关派生随机流，保存实际分配，避免随机调用次数影响未来算法比较。
- 不启用优化分频、反馈选星、弱项筛选、近似预测或跨时刻近似复用。

## 四、工作步骤

### 1. 核验并建立派生配置

核验冻结manifest；阅读V1.4.1记录和本文件。审计扩展站点、轨道和12条GSO关联，记录社区近似位置、仿真位置和未确认运营状态。另设实验配置、入口和输出目录。

### 2. 实现逐快照顺序推进

`传播→可见性→最大仰角选星→随机分频→保存输入→完整干扰计算与计时→保存结果→推进10秒`。

不必先生成完整两小时关联；边生成边计算，并保存位置/关联/频点用于离线回放。当前开环，结果不影响下一时刻决策。逐时刻运行不自动等同闭环或实时系统，也不自动得到槽内连续变化。

### 3. 先小段扩展试跑，再执行720帧

检查实际活动链路数、数值一致性、内存、耗时和输出体积。文件过大可分块压缩、保留输入及聚合指标并按需重建矩阵，不能省略参考计算来伪装加速。试跑通过后执行完整两小时。

### 4. 每快照记录结果和计时

| 类型 | 内容 |
|---|---|
| 输入/规模 | 时间、候选数、站点活动数、关联、频点、活动链路总数、实际计算干扰对数与窗口数 |
| NGSO | 失效链路ID/数量、瞬时LF、I/N、分运营商和三类来源统计 |
| GSO | 12站各口径/带宽/窗口的Starlink、OneWeb及合计EPFD，峰值窗口 |
| 干扰耗时 | 直接测量整体干扰wall time，另计NGSO、GSO、共享准备、聚合及指标统计 |
| 流程耗时 | 轨道传播、选星、随机分频、输入/结果输出和整个快照处理时间 |

使用单调高精度时钟。整体干扰耗时不能靠重复相加共享分项代替。网页绘制不计入，I/O另计。双端离轴角等逐对几何不能提前算完后藏在计时范围外。保存平台/依赖/线程与并行策略、预热说明。

### 5. 汇总两小时曲线和报告

必需：失效链路数和瞬时LF曲线；12站EPFD曲线；720帧总干扰计算耗时及NGSO/GSO分项曲线；活动链路/干扰对数与耗时对应关系。

耗时统计总和、均值、中位数、P95、最大值。全时间LF主汇总为失败链路样本总数/活动链路样本总数，另报逐帧均值需区分；均不等同连续时间失效时长比例。

### 6. 建设网页回放

读取预计算结果，播放不触发全量重算。提供时间轴、播放/暂停、跳转、按系统/站点筛选；显示当前活动数、失效数、LF、12站EPFD与耗时；链路分层显示，避免大规模连线遮挡。

GSO默认建议1m、40kHz、两系统合计在已评价窗口中该带宽子集的最大EPFD；显示峰值窗口，可切换1/2/5m、40kHz/1MHz和单系统/合计。12站曲线可小图或选站显示。

保护线匹配配置，先标“100%时间瞬时参考上限”：本频段表列1/2/5m，40kHz为−164dB(W/m²)，1MHz为−150dB(W/m²)。单系统关联Article22表22-1B，合计关联第76号决议表1B；端点相同不表示完整曲线相同。采样未超限不等同连续时间安全或统计合规。

### 7. 核验并固化扩展基准

核查链路约束、随机频道规则、功率单位、系统贡献求和、零EPFD和缺失值；抽样对照既有模型。保存输入输出哈希、配置、环境及复现命令。未来快速算法先使用同输入比较耗时/误差/漏检，再研究反馈闭环。

## 五、沿用参数与代码入口

- 12dBW/活动100MHz载波，来源2025精读论文TableI；NGSO噪声398K，LF按I/N严格大于−12.2dB。
- S.1528-0 1.2圆波束：18.2GHz处35dBi、半宽1.499050°、旁瓣−20dB，固定有效口径跨频率缩放；半宽/效率/旁瓣为研究假设。用户已确认核查报告有效，不再要求获取S.1528-0原文。
- S.1428-1接收方向图，NGSO口径约1.317496m；GSO独立1/2/5m，原3.5m元数据保留。
- EPFD：平坦矩形谱/理想窗口、谱重叠、窄窗口交集中点增益、FSPL及线性求和。30窗口=8中心+7边界×两带宽，非全频最坏值搜索。
- `backend/app/services/feeder_association.py`：几何/选星。
- `backend/app/services/feeder_interference.py`：方向图、NGSO矩阵/聚合。
- `backend/app/services/feeder_gso_epfd.py`：谱窗口/EPFD。
- `backend/app/services/feeder_fast_interference.py`：已有筛选原型，当前更慢，新基准不启用。
- `scripts/run_feeder_gso_epfd.py`：现有61帧入口，新实验另建入口。

暂不追加槽内细采样、完整合规统计、AI、QoS/路由/业务调度。模型继续保留适用边界，不因此不断扩张物理实现。
